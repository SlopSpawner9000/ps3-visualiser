# Bundled fonts

Free fonts that the built-in UI themes fall back on when the font they were designed around isn't installed.
Each comes with its licence; all allow free redistribution.

| File | Font | Used by | Licence |
| --- | --- | --- | --- |
| `selawk.ttf` | Selawik 1.01 (Microsoft's open Segoe UI stand-in) | Metro-style, Glossy Aero-style, Neumorphism | SIL Open Font License 1.1, `Selawik-OFL.txt` |
| `Roboto-Variable.ttf` | Roboto (google/fonts' `Roboto[wdth,wght].ttf`, renamed; drawn in its Regular style) | Material-style, Flat-style | SIL Open Font License 1.1, `Roboto-OFL.txt` |
| `DejaVuSans.ttf` | DejaVu Sans 2.37 | Brushed Metal-style, Classic 95-style, Brutalist | Bitstream Vera licence + public domain, `DejaVu-LICENSE.txt` |
| `DejaVuSansMono.ttf` | DejaVu Sans Mono 2.37 | Terminal-style, Synthwave (glyphs Orbitron lacks) | Bitstream Vera licence + public domain, `DejaVu-LICENSE.txt` |
| `Cantarell-Regular.ttf` | Cantarell (GNOME's own interface font) | Adwaita-style | SIL Open Font License 1.1, `Cantarell-OFL.txt` |
| `Orbitron[wght].ttf` | Orbitron (google/fonts, variable; drawn in its Regular style) | Synthwave | SIL Open Font License 1.1, `Orbitron-OFL.txt` |

Sources: https://github.com/microsoft/Selawik/releases/tag/1.01,
https://github.com/google/fonts/tree/main/ofl/roboto,
https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37,
